## Project Details
- **Project Name:** Node.js HTTP Server
- **Student Name:** Saikeerthan Reddy
- **Section:** CSE-2A
- **Technology Used:** Node.js, JavaScript
- **Port Number:** 3000

## Aim
To create a basic HTTP server using Node.js and display different pages using URL routing.

## Features
1. Home Page – Displays the welcome message.
2. About Page – Displays student name and section.
3. Time Page – Displays the current date and time.
4. Error Page – Displays a 404 Page Not Found message.

## Technologies Used
- Node.js
- JavaScript
- Visual Studio Code
- Google Chrome

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   `node server.js`

4. Open Chrome and visit:

   - Home: http://localhost:3000/
   - About: http://localhost:3000/about
   - Time: http://localhost:3000/time
   - Error: http://localhost:3000/error
